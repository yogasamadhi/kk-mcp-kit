# kk-mcp-workspace

Read-only discovery, repository inspection, instruction lookup, dependency graph analysis, and
bounded workspace search for configured local roots.

Run either runtime against the same build:

```bash
node dist/cli.mjs --config /absolute/path/to/kk-mcp.config.json
bun dist/cli.mjs --config /absolute/path/to/kk-mcp.config.json
```
