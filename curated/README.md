# 第三方 MCP 精选目录

这些 MCP Server 由各自的上游团队维护。本目录收录项目介绍和官方链接，安装、授权和配置方法见对应的上游说明。

| 使用场景 | 项目 | 维护方 | 适合用来做什么 | 官方来源 |
| --- | --- | --- | --- | --- |
| 代码协作 | GitHub MCP Server | GitHub | 在客户端中查找相关 Issue、阅读 PR，查看仓库文件。 | [项目仓库](https://github.com/github/github-mcp-server) |
| 开发文档 | Context7 | Upstash | 编写或升级依赖库的调用代码时，检索该库的文档和用法示例。 | [项目仓库](https://github.com/upstash/context7) |
| 开发文档 | Microsoft Learn MCP Server | Microsoft | 开发 Azure 或 .NET 应用时，查找微软官方技术文档和代码示例。 | [项目仓库](https://github.com/MicrosoftDocs/mcp) |
| 故障排查 | Sentry MCP | Sentry | 根据线上报错查找对应的 Sentry Issue，并结合错误事件和调用链排查原因。 | [项目仓库](https://github.com/getsentry/toolkit#sentry-mcp) |
| 团队知识库 | Notion MCP | Notion | 搜索团队工作区，读取项目页面，把会议记录整理成文档。 | [官方文档](https://developers.notion.com/guides/mcp/overview) |
